    File on disk

    Store, query and update records in plain text or binary files.

    FileDB is a small database engine written in C. The same C code runs in the terminal and, compiled to WebAssembly, on this page. Each table is one file, stored as text or binary.

    How a command runs

    1. Split the line into words

      tokenize() splits at spaces. Text in double quotes stays one word.

      findstudentsmarks>80

    2. Load the table

      load_table() reads the file into a Table struct in memory.

    3. Do the work

      find uses linear search, sort uses bubble sort. Numbers compare as numbers, so 9 < 78.

    4. Save to the file

      • Insert appends to the end of the file.
      • Update (binary) jumps to the record with fseek() and overwrites only it.
      • Update or delete (text) rewrites the whole file.

    Text vs binary

    Text

    students.txt
    id,name,marks↵
1,Ravi,85↵
2,Anita,92↵

    35 bytes

    Readable and small, but lines have different lengths, so a change rewrites the file.

    Binary

    students.bin
    46 44 42 31 03 00 00 00
69 64 00 00 … 32 bytes per name
31 00 00 00 … 32 bytes per value

    296 bytes

    Bigger, but every record is the same size, so any record can be changed in place.

    position of record N = header + N × record size

    With 3 columns: header = 4 + 4 + 3 × 32 = 104 bytes, record = 3 × 32 = 96 bytes. Record 1 starts at byte 200.
