        Class project in C

        Store, query and update records in plain text or binary files.

        FileDB is a small database engine written in C. The same C code runs in your terminal and, compiled to WebAssembly, in this page. Every table is one file, and you choose whether that file is text or binary.

        What happens when you press Enter

        Every command goes through the same four steps.

        1. Split the line into words

          tokenize() breaks the line at spaces. Text inside double quotes stays together as one word.

          findstudentsmarks>80

        2. Load the table into memory

          load_table() opens data/students.txt (or .bin) and reads every record into a Table struct.

          typedef struct {
    char values[MAX_COLS][MAX_LEN];  /* 10 x 32 */
} Record;

        3. Do the work

          find checks every record one by one (linear search). sort uses bubble sort. Numbers are compared as numbers, so 9 comes before 78.

        4. Save the result to the file

          Each change is saved the cheapest way the format allows:

          • Insert appends one record to the end of the file (fopen mode "a").
          • Update, binary file jumps to that record with fseek() and overwrites only it.
          • Update or delete, text file rewrites the whole file, because lines have different lengths.

        The same records, stored two ways

        You pick the format when you create a table, and can switch later with convert.

        Plain text

        students.txt
        id,name,marks↵
1,Ravi,85↵
2,Anita,92↵

        35 bytes

        • Opens in Notepad or Excel.
        • Small: only the characters you typed are saved.
        • Lines have different lengths, so changing one value means rewriting the file.

        Binary

        students.bin
        46 44 42 31 03 00 00 00
69 64 00 00 … 32 bytes per column name
31 00 00 00 … 32 bytes per value

        296 bytes

        • Every record is exactly the same size.
        • So the program can jump straight to record N and change it in place.
        • Bigger, because unused space is filled with zeros. Not readable by people.
        position of record N = header size + N × record size

        Records are numbered from 0. With 3 columns, the header is 4 (FDB1) + 4 (column count) + 3 × 32 = 104 bytes, and each record is 3 × 32 = 96 bytes. So record 1 (Anita) starts at byte 104 + 1 × 96 = 200.

        Inside the code

        Four files, each with one job.

        filedb.h

        Shared definitions: the Record and Table structs, the size limits, and the list of functions.

        storage.c

        Everything that touches files: load, save, append, and in-place overwrite with fseek().

        commands.c

        Understands what you typed: splits it into words, checks it, and runs the command.

        main.c

        The terminal loop: show a prompt, read a line, run it, repeat. This web page calls execute() directly instead.

        Run it on your computer

        You need a C compiler (gcc or clang) and make.

        # build and start the program
make
./filedb

# run the 34 automatic tests
make test

# rebuild this web version (needs Emscripten)
make web
